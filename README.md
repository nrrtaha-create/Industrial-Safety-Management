# نظام إدارة الأمن والسلامة في المنشآت الصناعية
# Industrial Safety Management System

نظام شامل وحديث لإدارة الأمن والسلامة في المنشآت الصناعية بكفاءة عالية

## 🎯 الميزات الرئيسية

### 1. إدارة الحوادث والإصابات
- تسجيل الحوادث والإصابات المختلفة
- متابعة تطور الحالات الصحية
- توليد تقارير تحليلية للحوادث
- تصنيف الحوادث حسب الشدة والنوع

### 2. معايير السلامة والامتثال
- متابعة معايير السلامة الدولية (ISO 45001, OHSAS)
- إدارة قائمة المراجعة اليومية والدورية
- تتبع الامتثال للقوانين واللوائح
- تنبيهات الانتهاكات والمخاطر

### 3. إدارة معدات الحماية الشخصية (PPE)
- تسجيل وتتبع معدات الحماية
- تنبيهات صلاحية الاستخدام
- صيانة دورية للمعدات
- توزيع المعدات على العاملين

### 4. التفتيش والجولات الأمنية
- جداول تفتيش دورية منتظمة
- تسجيل نتائج الجولات الأمنية
- صور وملاحظات توثيقية
- متابعة الإجراءات التصحيحية

### 5. التدريب والتوعية
- برامج تدريبية شاملة
- اختبارات الكفاءة والمهارات
- شهادات التدريب
- متابعة مستوى الوعي الأمني

### 6. التقارير والإحصائيات
- تقارير شاملة عن الحوادث
- معدلات الحوادث والإصابات
- تحليل الاتجاهات والأنماط
- تقارير الامتثال الشهرية والسنوية

## 📋 المتطلبات

- Python 3.9+
- Django 4.0+
- PostgreSQL / MySQL
- Node.js 16+ (للواجهة الأمامية)
- Docker (اختياري)

## 🚀 التثبيت والتشغيل

### 1. استنساخ المستودع
```bash
git clone https://github.com/nrrtaha-create/Industrial-Safety-Management.git
cd Industrial-Safety-Management
```

### 2. تثبيت المتطلبات
```bash
pip install -r requirements.txt
```

### 3. إعداد قاعدة البيانات
```bash
python manage.py migrate
```

### 4. إنشاء مستخدم إداري
```bash
python manage.py createsuperuser
```

### 5. تشغيل الخادم
```bash
python manage.py runserver
```

ثم افتح المتصفح على: `http://localhost:8000`
